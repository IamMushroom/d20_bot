# Backlog проекта

Здесь хранятся продуктовые хотелки и технические задачи. Один файл соответствует одному
направлению; устойчивые ID можно использовать в коммитах и pull request.

## Активные направления

| Направление | Файл | Статус |
|---|---|---|
| Web-панель | [web-panel.md](web-panel.md) | активно |
| Базовые броски | [dice.md](dice.md) | активно |

## Отложено

| Направление | Файл | Статус |
|---|---|---|
| Foundry VTT 14 | [foundry-vtt.md](foundry-vtt.md) | backlog, не начинать без отдельного решения |
| Рекапы | [recaps.md](recaps.md) | backlog, не начинать без отдельного решения |
| Технический долг | [technical-debt.md](technical-debt.md) | по мере необходимости |

## Правила

- Новую хотелку добавлять в тематический файл отдельным чекбоксом.
- Для нового направления создавать отдельный файл и добавлять его в этот индекс.
- Завершённые задачи отмечать `[x]`, не удаляя до ближайшего релиза.
- Существенные изменения поведения дополнительно описывать в `CHANGELOG.md`.
- Backlog-задачи не брать в работу без явного решения владельца проекта.
