# Базовые броски

Цель: развивать основную standalone-функцию бота без зависимости от Core, базы и web-панели.

## UX и выражения

- [x] `DICE-001` Сделать сообщения об ошибках parser понятными пользователю и указывать проблемный
  фрагмент выражения.
- [x] `DICE-002` Улучшить формат результата: исходное выражение, отдельные кости, модификатор и итог.
- [x] `DICE-003` Добавить Foundry-совместимые `k`/`kh`/`kl` с необязательным количеством;
  `2d20kh` — преимущество, `2d20kl` — помеха.
- [x] `DICE-004` Добавить `/reroll` для последнего успешного броска без изменения быстрого меню.
- [x] `DICE-005` Проверить и документировать граничные ограничения: число костей, число граней и
  максимальная длина выражения.

## Сохранённые формулы

- [ ] `DICE-101` Спроектировать сохранённые формулы так, чтобы standalone оставался самодостаточным.
- [ ] `DICE-102` Решить, достаточно ли Telegram-команд/локального состояния или хранение должно быть
  только опциональной connected-функцией.
- [ ] `DICE-103` Не добавлять сохранённые формулы до фиксации модели хранения и поведения после
  перезапуска.

Команды `/roll`, `/roll20` и `/duality` должны оставаться быстрыми, понятными и доступными без Core.
